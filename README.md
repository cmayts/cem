Developed a real-time UAV direction-finding system using a synchronized
four-microphone array and an XVF3800-based acquisition system.

- 400 field-recorded UAV audio samples
- Real-time azimuth estimation
- 4 synchronized microphone channels
- 20-stage signal processing and filtering pipeline
- Tested under different devices and field conditions
